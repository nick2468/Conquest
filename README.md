# Conquest

A turn-based territory game set in Australia.

Built by James and Nick. Written in TypeScript. It runs as a web app you add to
the iPad Home Screen, and in a web browser on a desktop or laptop computer.

Read [DESIGN-BRIEF.md](DESIGN-BRIEF.md) first. It holds every decision and the
plan.

## Status

Phase 0. No code yet. The design is agreed and the repository is set up.

## Plan

1. The rules engine and a hot-seat game on one iPad.
2. Computer opponents.
3. The Home Screen app wrapper, published to `conquest.datacrafter.net`.
4. Custom maps.
5. Several players on separate devices, plus computer players.
